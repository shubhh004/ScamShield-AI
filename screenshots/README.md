| `dashboard.png` | Main dashboard with activity summary |

| `email-scanner.png` | Email body analysis result |

## Naming Convention

- Format: PNG, minimum 1440×900
- Filename: kebab-case, descriptive
- Dark mode only (the application is dark-mode first)
